# Webhook Subscriptions

Everything about your Webhook Subscriptions.

## Endpoints

| Method | URL | Description |
|--------|-----|-------------|
| GET | `/public-api/webhook-subscriptions` | [Get all webhook subscriptions](./get-webhook-subscriptions.md) |
| POST | `/public-api/webhook-subscriptions` | [Create a new webhook subscription](./create-webhook-subscription.md) |
| DELETE | `/public-api/webhook-subscriptions/:webhookSubscriptionId` | [Delete a webhook subscription](./delete-webhook-subscription.md) |
| POST | `/public-api/webhook-subscriptions/:webhookSubscriptionId/test` | [Test a webhook subscription](./test-webhook-subscription.md) |
